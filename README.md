# StackDrop

Storefront for digital products (courses, kits and infographics) for developers, in Spanish.

**Live demo:** https://gleimbek.github.io/StackDrop/

> 🚧 **Work in progress.** Payments aren't connected yet. Checkout doesn't ask for payment details or charge anything; confirming the order only simulates the purchase.

## What it does

- **Catalog** with product cards, and a detail modal for each product
- **Cart** that adds and removes items and keeps a running total
- **Two-step checkout** (cart, then confirmation) that empties the cart and shows a confirmation message
- **Services, projects and about** sections, with links to live demos of other projects

## Built with

A single `index.html` with HTML, CSS and vanilla JavaScript, no build step. Icons from Font Awesome, fonts from Google Fonts.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
